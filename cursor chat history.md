Ты — экспертный фронтенд-разработчик и UI/UX дизайнер с сильным вкусом. Твоя задача — написать код для современного, живого и нешаблонного лендинга для ремесленной обжарки кофе «Кварта» (Минск)[cite: 2, 3]. 

Сайт должен выглядеть так, будто его создала крутая дизайн-студия вручную, а не сгенерировал искусственный интеллект по шаблону Bootstrap/Tailwind UI (никаких избитых фиолетовых градиентов, банальных карточек с иконками по центру и безликого стока)[cite: 3].

### 1. Используемый стек и архитектура
- **Фреймворк:** Next.js (App Router)[cite: 4] + React
- **Стилизация:** Tailwind CSS
- **Иконки:** Lucide React
- **Анимации:** Tailwind CSS transitions / Framer Motion (аккуратно, плавно, без перегруза и фризов на мобилках)[cite: 4]
- **Бэкенд/API:** Next.js API Routes (`app/api/lead/route.dp.ts` или аналогичный)
- **База данных / Хранилище:** SQLite (через `better-sqlite3` или Prisma) либо простое логирование в JSON-файл с объяснением в README (выбери надежный и простой локальный вариант для тестового)[cite: 4].
- **Дополнительно:** Интеграция с Telegram Bot API для дублирования заявок (опционально/настраиваемо через env-переменные)[cite: 4].

### 2. Контекст и смыслы (О чем проект)
- **Кто они:** Маленькая мастерская из Минска, обжаривают кофе небольшими партиями по 5 кг с 2019 года[cite: 2]. Основатели — Аня и Дмитрий, бывшие бариста[cite: 2].
- **Философия / Главное УТП:** Свежесть. Обжаривают по четвергам, развозят по пятницам. Зерно приходит клиенту на 1–3 день после обжарки[cite: 2].
- **Целевая аудитория:** 25–45 лет, пьют дома или в офисе. 90% трафика идет с мобильных телефонов из таргета (Instagram/Яндекс)[cite: 3].
- **Тон коммуникации:** Тёплый, простой, честный, ремесленный, без пафоса и «премиального» глянца[cite: 3].

### 3. Структура лендинга
1. **Первый экран (Hero):** 
   - Нестандартная, смелая типографика, живой заголовок (например, про четверги и свежесть).
   - Кнопка быстрого перехода к каталогу или подписке.
   - Указание города (Минск) и свежести обжарки.
2. **Блок «Кто мы и почему свежесть — это всё»:**
   - История Ани и Дмитрия. Акцент на микро-партии по 5 кг и логистику (четверг/пятница)[cite: 2].
3. **Каталог продукции и цены (с актуальными данными из ТЗ):**
   - Эфиопия Иргачеффе (32 BYN, цветочный, бергамот, светлая обжарка, 250 г)[cite: 2].
   - Колумбия Уила (29 BYN, карамель, красное яблоко, 250 г)[cite: 2].
   - Бразилия Серрадо (26 BYN, орех, шоколад, под эспрессо, 250 г)[cite: 2].
   - Дрип-пакеты, ассорти (18 BYN / 10 штук)[cite: 2].
4. **Блок «Подписка» (Флагманский продукт):**
   - 54 BYN / мес: 2 пачки по 250 г раз в месяц, доставка бесплатно[cite: 2]. Выгодное предложение для постоянных клиентов.
5. **Доставка и самовывоз:**
   - Самовывоз: Минск, ул. Короля, 9 (пн-пт 8:00–20:00, сб-вс 10:00–18:00)[cite: 2].
   - Доставка по Минску: по пятницам, при заказе от 50 BYN — бесплатно[cite: 2].
6. **Форма заявки и Контакты (Главная цель):**
   - Поля: Имя, Телефон, Что интересует (Подписка / Разовый заказ / Вопрос), Комментарий[cite: 3].
   - Кнопка отправки с индикацией загрузки (loading state).

### 4. Жесткие технические требования и защита от багов
Напиши код с учетом следующих требований надежности:
1. **Валидация телефона (Беларусь):**
   - Поле телефона должно строго валидировать белорусские номера (форматы вроде `+375 (XX) XXX-XX-XX` или аналогичные локальные). 
   - При неверном формате пользователь должен видеть понятную, не раздражающую подсказку прямо под полем до отправки[cite: 4].
2. **Защита от дубликатов и двойного клика (Anti-spam / Anti-double-click):**
   - На фронтенде: заблокируй кнопку отправки (`disabled`, спиннер) сразу после клика.
   - На бэкенде (`/api/lead`): реализуй защиту от повторной отправки того же номера телефона в течение 10 минут (если клиент случайно нажал дважды или отправил форму повторно, вторая заявка не должна создаваться в базе, но пользователь должен увидеть сообщение об успехе)[cite: 4].
3. **Трекинг источников (UTM-метки):**
   - Автоматически собирай параметры из URL (utm_source, utm_medium, utm_campaign, referrer) и передавай их вместе с заявкой на бэкенд, чтобы менеджер понимал, из какой рекламы пришел клиент[cite: 4].
4. **Обработка сетевых ошибок:**
   - Если пропал интернет или сервер упал, пользователь не должен зависнуть в состоянии вечной загрузки. Покажи понятный статус ошибки («Не удалось отправить заявку. Проверьте соединение или позвоните нам напрямую») с возможностью повторить попытку[cite: 4].
5. **SEO и OpenGraph (Метатеги):**
   - Настрой мета-теги и OpenGraph (картинка, заголовок, описание) для красивого превью при шеринге ссылки в Telegram, Viber или соцсетях[cite: 4].
6. **Адаптивность и производительность:**
   - Верстка строго Mobile-First (так как 90% идут со смартфонов)[cite: 3].
   - Оптимизация изображений (используй компоненты `next/image` с качественными, но легкими фото кофе/зерен с Unsplash/Pexels).
